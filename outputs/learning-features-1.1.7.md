# 学习功能范围

依据用户指定聊天 “Moodle Course Page” 中整理的 Foundations of Programming 课程主题：Python 基础、对象与字符串、条件、列表与元组、循环与字典、函数、文件读写、面向对象、绘图和算法练习。没有读取或分发课程答案。

1. 本机新建练习 Notebook：提供笔记和代码两个空白单元格，学习者自己填写；支持现有导入器导入 ipynb。
2. 运行至此：从开头重跑到选定单元格，先本机检查相同范围，再由服务器顺序运行，便于按步骤练习变量、循环与函数。
3. 清除 Notebook 输出：保留题目、代码和元数据，便于重新练习，用户主动保存才写回远端。

暂不加入插件市场、变量管理器、多语言内核、协作编辑及课程管理后台。input() 交互与 IPython 魔法仍需独立实现，并非本轮已支持功能；课程涉及的绘图库等依赖也需要本机与服务器环境一致。结果区和已保存 PNG 预览沿用现有功能。
